# Решения по переносу Super Bunny → Super Bunny JS

Зафиксированы в `PLAN.md` и подтверждены пользователем.

## Технические решения

- Физика: `planck` (JS-реализация Box2D-подобного семейства) вместо собственной физики с нуля.
- Рендер: `three` + `WebGLRenderer`; физика в XY (`+Y` вверх), преобразование в Three `(x, y, z)Unity → (x, y, -z)Three`.
- Шаг физики: `dt = 0.02`, velocity iterations 50, position iterations 3, gravity `-7.8`.
- Модель персонажа: GLB/glTF 2.0 через `GLTFLoader`; Draco/KTX2 не подключали.
- Сравнение с Unity: эталон в `reference/unity-runtime/`, физическая идентичность не заявалась.

## Scope и поведение

- Полный перенос включал Deathmatch, карты, жизни, звук, меню, replay, debug.
- Сетевой режим и новые режимы, отсутствующие в Unity, не добавлялись.
- Управление — клавиатура, как в исходнике; клавиши определяются по физическому коду (работают при русской раскладке).
- Разворот персонажа по `S` — исключён по решению пользователя; направление профиля постоянно `facing = +1`.
- Звук Web Audio; автозапуск блокируется действием пользователя; `?mute=1`.

## Проверки

- Vitest (Node): физика, захваты, лианы, пружины, прыжки, replay.
- Playwright: браузерные сценарии (4 игрока на Meadow, управление P2, запись/воспроизведение, пауза/reset, debug, узкое окно, реальный матч).
- Сборка: `npm run build` (TypeScript strict + Vite).
